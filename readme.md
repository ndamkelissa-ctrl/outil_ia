# TaskFlow - Gestionnaire de Tâches

TaskFlow est une application simple et intuitive de gestion de tâches (To-Do List) développée dans le cadre du module Outils IA. Elle permet d'organiser ses activités quotidiennes en toute simplicité.

---

## Fonctionnalités Principales

L'application couvre 5 fonctionnalités clés :

1. Ajout de tâches : Création rapide d'une tâche avec un titre et une date automatique.
2. Affichage de la liste : Visualisation claire des tâches avec indicateur de statut.
3. Validation de tâches : Marquage d'une tâche comme terminée ou remise à faire.
4. Suppression de tâches : Retrait définitif d'une tâche de la liste après confirmation.
5. Filtrage des tâches : Tri et affichage par statut (Toutes, À faire, Terminées).
